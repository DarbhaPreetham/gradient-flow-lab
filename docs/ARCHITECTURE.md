# ChromaWeave Architecture

This document explains how the core game, state, audio, and cloud sync fit together.

---

## 1. Game engine

The game board is rendered on a single HTML5 `<canvas>` element inside `src/components/GameBoard.tsx`. Canvas was chosen over DOM tiles for:

- **60 FPS animations** during drag and swap.
- **Consistent performance** on large Master grids (up to 10×10).
- **Smooth shadows, rounded corners, and glows** without layout thrashing.
- **Large hitboxes** for accessibility — tiles can be grabbed slightly outside their visual bounds.

### Tile model

Each tile stores:

- `col`, `row` — its fixed grid position.
- `dx`, `dy` — animated display position (may differ during a drag/lerp).
- `color` — the RGB color currently shown.
- `targetIndex` — the grid index this color truly belongs to.
- `anchor` — whether the tile is locked in place.

A level is solved when every non-anchor tile's `targetIndex` equals its current `row * cols + col`.

### Interaction flow

1. `onPointerDown` — identify the tile under the pointer; reject anchors.
2. `onPointerMove` — track the dragged tile and highlight the nearest valid drop target.
3. `onPointerUp` — swap colors and `targetIndex` between the two tiles, then animate both back into their grid slots.
4. `requestAnimationFrame` loop — handles lerps, hint glow, and continuous redraw.

### Difficulty scaling

| Group | Grid sizes | Anchors | Notes |
|-------|------------|---------|-------|
| Beginner | 4×4, 5×5 | 4 corners only | Gentle color flows, small boards |
| Casual | 6×6, 7×7 | 4 corners only | More tiles, subtler gradients |
| Master | 9×9, 10×10 | 4 corners + 1–2 interior anchors | Extra palette control points create non-linear gradients |

Interior anchors in Master levels force the player to reason about multiple gradient centers, not just the four edges.

## 2. Color system

`src/utils/colors.ts` defines all color math.

- `hexToRgb` / `rgbToCss` — conversion helpers.
- `lerpRgb` — linear RGB interpolation.
- `bilinear` — corner-to-corner gradient for simple levels.
- `multiPoint` — inverse-distance weighting for levels with interior palette control points.
- `targetColor(level, col, row)` — returns the exact RGB a tile at `(col, row)` should have.

The **Goal preview** in the top-left corner is generated by `generatePreview(level, size)` in `GameBoard.tsx`, which draws the full target gradient to a small canvas and returns a data URL.

## 3. State & persistence

`src/utils/storage.ts` manages local state in `localStorage` under the key `chromaweave:v1`.

```ts
type SaveData = {
  settings: { sound: boolean; haptics: boolean; colorBlind: boolean; theme: "light" | "dark" };
  unlocked: string[];      // level ids
  completed: string[];       // level ids
  best: Record<string, number>; // best move count per level
  tutorialSeen: boolean;
};
```

### SSR safety

The app uses `loadSave.defaults()` for the initial render so server and client markup match. A `useEffect` then hydrates the real saved state from `localStorage`.

### Cloud sync

When a user signs in, `src/utils/cloudSync.ts`:

1. Fetches the remote `game_progress` row.
2. Merges it with local progress (union of unlocked/completed, lowest move count wins).
3. Pushes the merged result back to the server.
4. Pushes again whenever unlocked/completed/best changes.

This gives **offline-first play** with automatic backup when signed in.

## 4. Audio

`src/utils/audio.ts` uses the Web Audio API to synthesize all sounds in real time — no external audio files are downloaded.

- **Ambient pad** — A2/E3/A3 detuned sines with a slow LFO low-pass sweep, fades in over 4s.
- **Swap chime** — random pentatonic note + fifth, gently filtered.
- **Drag hum** — low sine that rises while a tile is held.
- **Tap** — short 880Hz sine.
- **Victory** — warm C-major arpeggio pad with shimmer.

Audio is disabled until the first user gesture (`unlockAudio`), respecting browser autoplay policies.

## 5. Authentication

`src/components/AuthScreen.tsx` and `src/hooks/useAuth.ts` handle:

- Email + password sign-up and sign-in.
- Password reset.
- Google OAuth via Lovable Cloud auth.

`src/routes/auth.tsx` is marked `ssr: false` because Supabase sessions live in `localStorage` and are unavailable during SSR.

When a new user is created, the database trigger `handle_new_user()` automatically inserts a `profiles` row and a `game_progress` row.

---

## 6. Routing

TanStack Start file-based routing:

- `/` — Home + game shell.
- `/auth` — Sign in / sign up.
- `/mcp` — MCP server endpoint for agents.
- `/.mcp/invoke-tool/$tool` and `/.mcp/list-tools` — Auto-generated MCP routes.
- `/.lovable/oauth/consent` — OAuth consent screen for agent connections.

The root route (`src/routes/__root.tsx`) sets PWA metadata, manifest, fonts, and the QueryClient provider.
